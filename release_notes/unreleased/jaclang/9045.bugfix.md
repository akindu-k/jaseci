- **Fix: Unset `jac.toml` environment variables now fail loud**: `${VAR}` and `${VAR:?message}` values with no environment variable set now reject the configuration with an error naming the setting that needs it, instead of silently passing through as literal text. Every command that reads `jac.toml` enforces this, so export the variable or switch to `${VAR:-default}` for values that only some commands need.
