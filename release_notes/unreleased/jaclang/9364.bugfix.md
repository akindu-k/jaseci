- **Fix: a `${VAR:+alt}` or `${VAR:0:3}` in `jac.toml` no longer slips past the deploy check** (#9184): jac reads `${VAR}`, `${VAR:-default}` and `${VAR:?message}`, and any other `${...}` form was passed over in silence rather than refused, so `jac scale deploy` shipped it into a Secret or a target setting as literal text and exited clean. A form jac does not read is now reported the same way an unset variable is, naming the setting and the text that would have shipped, and it is reported even when the variable is set, because the literal would reach the cluster either way. A `${1}` in a script stays a shell positional and is left alone.
